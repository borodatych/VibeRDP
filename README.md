# VibeRDP

Open-source RDP-клиент для macOS на замену Microsoft Windows App.

> **Статус:** ранняя разработка. Приложение подключается к Windows по NLA или TLS с проверкой сертификата, показывает рабочий стол и передаёт мышь с прокруткой и клавиатуру с привычными ⌘C и ⌘V; буфера обмена ещё нет. Что умеет — [docs/functional.md](docs/functional.md), сборка — [docs/manuals/devSetup.md](docs/manuals/devSetup.md), план — [docs/roadmap.md](docs/roadmap.md), сборки CI — во вкладке Actions.

## Что решает

- **Буфер обмена, который работает.** Скопированное на Маке сразу доступно в Windows — без переключения фокуса туда-обратно
- **Независимые окна.** Окна Windows-приложений открываются как отдельные окна macOS: своё место в Mission Control и Cmd+Tab, своя иконка

## Режимы

Клиент выбирает режим сам; если режим недоступен, переходит к следующему без ошибок для пользователя:

| Режим | Когда | Как |
|---|---|---|
| **RAIL** (RemoteApp) | На хосте разрешён RemoteApp (нужен админ), режим включён в профиле | Нативный RAIL-канал RDP |
| **Seam** | На хосте запущен `vibe-seam-helper` (админ не нужен) | Хелпер шлёт список окон и их геометрию по своему каналу, клиент показывает каждое окно отдельным окном macOS |
| **Desktop** | Ни то, ни другое | Обычный рабочий стол, но с нормальным буфером |

## Устройство

| Папка | Что внутри |
|---|---|
| `core/` | `VibeRDPCore` — тонкая C-обёртка над FreeRDP 3.x |
| `client-macos/` | Приложение на Swift: AppKit + Metal, SwiftUI для настроек |
| `helper-win/` | `vibe-seam-helper` на Rust — хелпер Seam-режима для Windows |
| `protocol/` | Спецификация канала Seam |
| `docs/` | Концепт, план и база знаний — [docs/README.md](docs/README.md) |
