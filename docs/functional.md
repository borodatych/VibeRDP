## Подключение к Windows

**Список подключений:** главное окно показывает сохранённые подключения слева и настройки выбранного справа.
- «+» добавляет подключение, «−» удаляет выбранное вместе с его сохранённым паролем
- У подключения есть название, компьютер — имя или адрес, порт через двоеточие, IPv6 в квадратных скобках, — и пользователь в виде `ДОМЕН\пользователь` или `пользователь@домен`
- Изменения сохраняются сразу, кнопки «Сохранить» нет
- Подключает кнопка «Подключиться», Return или двойной щелчок по строке

**Пароли в связке ключей macOS:** пароль, введённый в поле или в вопросе, сохраняется после успешного входа, если стоит «Запомнить пароль в связке ключей»; неверный пароль не сохраняется.
Снятая галочка и кнопка «Забыть сохранённый пароль» сразу удаляют его.
В «Связке ключей» запись называется «VibeRDP: <название подключения>».
Сборка без подписи Developer ID при первом чтении пароля после обновления спрашивает доступ к связке — «Разрешать всегда» снимает вопрос.

**Пароль по запросу:** если у подключения нет пароля, VibeRDP спрашивает имя и пароль, когда их попросит компьютер; «Отмена» прекращает подключение.
Компьютер без NLA пароля заранее не требует — тогда пустой пароль ведёт на экран входа Windows.
После неверного пароля VibeRDP спрашивает снова и подключается заново.

**Шлюз удалённых рабочих столов (RD Gateway):** у подключения есть поле «Шлюз» — имя или адрес, порт через двоеточие, по умолчанию 443; пустое поле — подключение напрямую.
По умолчанию шлюз получает те же имя и пароль, что и компьютер, а один вопрос о пароле закрывает оба входа; для шлюза со своими учётными данными есть свой пользователь, а его пароль хранится в связке ключей отдельно («VibeRDP, шлюз: <название>»).
«Напрямую, если компьютер в локальной сети» — шлюз только для подключений извне.
Сертификат шлюза проверяется так же, как сертификат компьютера.
Сообщение шлюза показывается; если шлюз требует согласия с правилами, подключение ждёт «Принять» или «Отклонить».
Если шлюз не пустил, VibeRDP говорит об этом и снова спрашивает пароль.

**Импорт файлов .rdp:** «Файл → Импортировать файл .rdp…» (⌘O) добавляет подключения из файлов, которые сохраняют Windows App и mstsc; двойной щелчок по файлу в Finder добавляет и сразу подключает.
Из файла берутся компьютер с портом, пользователь с доменом и шлюз, название — имя файла; подключение к тому же компьютеру с тем же пользователем не дублируется, а выбирается.
Сохранённый в файле пароль Windows на Маке не расшифровать, поэтому он не переносится.
VibeRDP есть в «Открыть в программе» для файлов .rdp; сделать его программой по умолчанию — «Свойства» файла в Finder.

**Своя клавиатура у подключения:** «Как в настройках», «Как на Маке» или «Как на PC» — набор клавиш-модификаторов только для этого компьютера.

При первом подключении к компьютеру своей сети macOS спрашивает разрешение на доступ к локальной сети — VibeRDP объясняет, зачем он нужен.

**Защита соединения:** NLA или TLS — что поддерживает сервер.
Устаревший режим RDP Security с шифрованием без проверки сервера не используется.

**Вход в домен по Kerberos:** NLA сначала пробует Kerberos, а если он не сработал — NTLM, как Windows; поэтому VibeRDP входит и туда, где политика домена запрещает NTLM.
Настраивать ничего не нужно, если DNS домена отдаёт записи Kerberos, а пользователь записан с DNS-доменом: `ivanov@corp.example.com` или `corp.example.com\ivanov`; с кратким доменом `CORP\ivanov` вход пойдёт через NTLM.
Свои настройки Kerberos берутся из `/etc/krb5.conf`, `/Library/Preferences/edu.mit.Kerberos` и `~/Library/Preferences/edu.mit.Kerberos`.
Kerberos работает там, откуда виден контроллер домена, — в сети домена или через VPN; компьютер, заданный адресом IP, входит только через NTLM.
Билеты получает пароль подключения, хранятся они в памяти до конца сессии; билеты macOS VibeRDP не трогает.

**Проверка подлинности сервера:**
- Сертификат, которому доверяет Mac (системные и корпоративные корни связки ключей), принимается без вопросов
- Незнакомый сертификат показывается с причиной недоверия и отпечатком SHA-256; его можно принять один раз или запомнить
- Запомненный сертификат дальше принимается без вопросов
- Если сертификат сервера изменился после запоминания, VibeRDP предупреждает об этом, а кнопкой по умолчанию становится «Отмена»

**Причина неудачи — по-русски:** компьютер не найден, не принимает подключения, неверный пароль, ограничения учётной записи, смена пароля и другие; рядом — код движка для поддержки.

## Рабочий стол

**Рабочий стол Windows в окне:** после подключения окно показывает рабочий стол компьютера, а имя компьютера — в подзаголовке окна.
Сервер получает размер рабочего стола по размеру окна, а картинка вписывается в окно целиком: пропорции сохраняются, по краям — чёрные поля.
Если сервер сам меняет разрешение, картинка перестраивается на лету.
Кадры идут через графический конвейер RDPGFX, а от серверов без него — в RemoteFX.
В конвейере VibeRDP принимает H.264 в обоих видах — AVC420 и AVC444 с полной цветностью для чёткого цветного текста; декодирует его VideoToolbox, аппаратно там, где у Мака есть такой декодер.
На Retina картинка пока растянута вдвое.

**Переподключение:** если связь пропала — сменилась сеть, пропал Wi-Fi, Мак уснул, — VibeRDP сам восстанавливает подключение к тому же сеансу Windows: до 20 попыток с паузой 5 секунд.
Пока идёт переподключение, рабочий стол затемнён, видна попытка и кнопка «Отключиться»; нажатия этого времени в Windows не уходят.
После пробуждения Мака VibeRDP сразу проверяет связь, а не ждёт таймаута.
Если сеанс завершила сама Windows — выход, вход с другого компьютера — или перестал подходить пароль, VibeRDP не переподключается и говорит почему.

**Отключение:** пока идёт сессия, список подключений скрыт под рабочим столом, а завершает сессию пункт «Отключиться» в меню «Файл» или сочетание ⌥⌘W; сочетание меняется в настройках.
Пока идёт подключение, та же кнопка внизу окна его отменяет.
После отключения список возвращается со статусом; без сессии пункт неактивен.

**Во весь экран:** пункт «Во весь экран» в меню «Окно» или системное сочетание fn-F.

**Mac без Metal:** если Mac не может показать картинку, подключение не начинается, а окно объясняет почему.

## Буфер обмена

**Текст в обе стороны, сразу:** скопированное на Маке вставляется в Windows без переключений туда-обратно, скопированное в Windows — на Маке.
VibeRDP следит за буфером Мака всё время сессии и сообщает Windows о каждом копировании, а сам текст передаёт, только когда его вставляют.
Скопированное в Windows приходит на Мак тоже в момент вставки.
Русский текст, эмодзи и переводы строк сохраняются: Windows получает CRLF, Мак — обычные переводы строк.
**Оформленный текст:** вместе с простым текстом переносятся HTML и RTF — жирный, курсив, цвета, ссылки и таблицы, что копируется из Word, браузера, Pages или TextEdit.
Русский текст в HTML остаётся русским и в программах Мака.
Если в Windows скопировали то, чего VibeRDP пока не переносит, буфер Мака очищается, чтобы не вставилось старое.
Когда сессия кончается, скопированное в Windows и ещё не вставленное из буфера Мака пропадает.
**Картинки:** снимок экрана, картинка из браузера, Word или Paint переносится в обе стороны.
В Windows картинка с Мака вставляется и в программы, которые понимают PNG с прозрачностью, и в старые вроде Paint — у них прозрачное становится белым.
На Маке картинка с Windows вставляется и туда, где ждут PNG, и туда, где ждут TIFF.
Файлы — следующий шаг.

## Язык интерфейса

**Языки — файлами в папке** `~/VibeRDP/lang/`: положили файл перевода — язык появился в «Настройки → Язык» после перезапуска, удалили — исчез.
Русский вшит в приложение и работает всегда, даже без папки; английский приложение кладёт в папку само и возвращает, если файл удалили, но изменённый не трогает.
Непереведённые строки показываются по-русски — половина перевода уже полезна.
«Создать файл для правки» кладёт в папку полный русский каталог: исправленные там формулировки действуют во всех языках.
Выбор — «Как в системе» или конкретный язык; пропавший язык не залипает: берётся язык системы, а без его файла — русский.
Как сделать свой язык, хоть эльфийский, — спека [manuals/langSpec.md](manuals/langSpec.md), её можно целиком отдать языковой модели; образец с комментариями `example.jsonc` лежит в той же папке.
Вопрос macOS о доступе к локальной сети и название файлов `.rdp` в Finder переведены на английский внутри приложения.

## Мышь

**Мышь и трекпад над рабочим столом:** перемещение, левая, правая и средняя кнопки, перетаскивание; боковые кнопки «назад» и «вперёд» — если сервер их поддерживает.
Правый щелчок — правой кнопкой или двумя пальцами на трекпаде.
Control-щелчок остаётся левым щелчком и доходит до Windows как Ctrl-щелчок — выделение; ⌘-щелчок с настройками по умолчанию — тоже.
Щелчок по неактивному окну VibeRDP сразу доходит до Windows.

**Прокрутка:** колесо мыши, трекпад и Magic Mouse — по вертикали и по горизонтали, в направлении, выбранном в настройках macOS.
Щелчок колеса — щелчок колеса в Windows; прокрутка трекпада плавная, с инерцией, и даже медленное движение пальцев доходит.

**Курсор Windows:** над рабочим столом курсор такой, каким его рисует Windows: стрелка, текстовый курсор, рука, стрелки изменения размера.
Он прячется, когда Windows его прячет, и остаётся одного размера с картинкой рабочего стола; передвинуть курсор Mac сервер не может.

**Отзывчивость:** мышь не ждёт сети — на медленном канале окно не подвисает, а подряд идущие перемещения сливаются в одно.

## Клавиатура

**Клавиатура Мака в Windows:** пока окно VibeRDP активно и в нём рабочий стол, клавиши уходят в Windows по своему месту на клавиатуре, а символ выбирает раскладка Windows.
Цифры, знаки, стрелки, F-клавиши, цифровой блок и повтор удерживаемой клавиши работают как на клавиатуре PC.
Help работает как Insert, F13–F15 — как Print Screen, Scroll Lock и Pause.
Раскладку переключают в самой Windows, например ⌥⇧; синхронизации с раскладкой Мака пока нет.

**Модификаторы по умолчанию — «Как на Маке»:** ⌘C, ⌘V, ⌘Z, ⌘A и другие работают привычно, потому что левая ⌘ — это Ctrl.
Правая ⌘ — клавиша Windows: одна открывает «Пуск», с буквой даёт Win+E, Win+R и другие.
⌃ — Ctrl, ⌥ — Alt, правый ⌥ — AltGr.
Ctrl+Alt+Del в RDP заменяет Ctrl+Alt+End: ⌘⌥ + fn + →.

**Настройка клавиш:** меню VibeRDP → «Настройки…» → «Клавиатура».
- Каждой из шести клавиш — левой и правой ⌃, ⌥ и ⌘ — выбирается Ctrl, Alt или Windows; кнопки «Как на Маке» и «Как на PC» ставят готовый набор, во втором ⌘ — клавиша Windows
- Список сочетаний, которые остаются Маку: по умолчанию ⌘Q, ⌘H, ⌥⌘H, ⌘M, ⌘, (настройки), fn-F и ⌃⌘F (полный экран); остальные сочетания, ⌘W в том числе, получает Windows
- Сочетание для «Отключиться», по умолчанию ⌥⌘W; ⌫ при записи оставляет пункт без сочетания
- Галочка для клавиатур ISO, у которых между левым Shift и Z есть ещё одна клавиша: без неё эта клавиша и клавиша слева от 1 в Windows меняются местами
- Сочетание записывается нажатием, в нём обязательно ⌘, ⌃, ⌥ или fn; изменения действуют сразу
- «Вернуть по умолчанию» возвращает всё как было

**Без залипших клавиш:** если во время нажатия переключиться в другое приложение, Windows получает отпускание всех зажатых клавиш, а при возврате — состояние Caps Lock; Num Lock включён всегда, и цифровой блок печатает цифры.

**Что остаётся Маку всегда:** ⌘Tab, ⌘Space, снимки экрана ⌘⇧3/4/5 и блокировка ⌃⌘Q — их перехватывает сама macOS.
