## Подключение к Windows

**Подключение по имени или адресу** с портом через двоеточие, IPv6 — в квадратных скобках.
Пользователь вводится как `ДОМЕН\пользователь` или `пользователь@домен`.
Пароль вводится при подключении и нигде не сохраняется.
При первом подключении к компьютеру своей сети macOS спрашивает разрешение на доступ к локальной сети — VibeRDP объясняет, зачем он нужен.

**Защита соединения:** NLA или TLS — что поддерживает сервер.
Устаревший режим RDP Security с шифрованием без проверки сервера не используется.

**Проверка подлинности сервера:**
- Сертификат, которому доверяет Mac (системные и корпоративные корни связки ключей), принимается без вопросов
- Незнакомый сертификат показывается с причиной недоверия и отпечатком SHA-256; его можно принять один раз или запомнить
- Запомненный сертификат дальше принимается без вопросов
- Если сертификат сервера изменился после запоминания, VibeRDP предупреждает об этом, а кнопкой по умолчанию становится «Отмена»

**Причина неудачи — по-русски:** компьютер не найден, не принимает подключения, неверный пароль, ограничения учётной записи, смена пароля и другие; рядом — код движка для поддержки.

Изображения рабочего стола пока нет: после подключения окно показывает только его состояние.
