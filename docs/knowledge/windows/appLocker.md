# Windows: AppLocker и хелпер без админа

## Правила AppLocker по умолчанию не пускают exe из папки пользователя

**Контекст:** ключевой сценарий «корпоративная среда без админских прав» из [idea.md](../../idea.md) §1; установка хелпера копированием exe (§3.3); задача 8.2.

**Суть:**
- Правила AppLocker по умолчанию для исполняемых файлов: администраторам — любые файлы, всем пользователям — только из папки Windows (`%windir%\*`) и Program Files (`%programfiles%\*`)
- Правила исполняемых файлов действуют на любой PE-файл независимо от расширения

**Применение:**
- Там, где AppLocker включён с правилами по умолчанию, хелпер из папки пользователя не запустится
- Seam не включится, клиент по fallback останется в Desktop без ошибок — работа не ломается
- Пользователь не узнает причину: страница «почему не включился Seam» (8.2) должна называть и запрет запуска политикой

**Не проверено:**
- Как отличить «хелпер запрещён политикой» от «хелпер не установлен»: клиент видит только отсутствие `HELLO`, поэтому различить, вероятно, сможет лишь подсказка пользователю
