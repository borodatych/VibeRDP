# macOS: образ .dmg VibeRDP

Проверено 2026-09-25 на macOS 26.6.2, задача 2.6.
Скрипт — `client-macos/scripts/build-dmg.sh`, решение 32 в [decisions.md](../../decisions.md).
Общая механика окна установки — навык `dmg-installer`: фон двумя масштабами в одном TIFF, раскладка `ds_store` на невидимом для Finder томе, проверка готового образа.

## Ссылка на «Программы» показывается своим именем

**Суть:**
- Finder подписывает символическую ссылку её собственным именем: ссылка `Applications` на русской macOS показывается как «Applications», хотя сама папка в боковом меню — «Программы» — видно на снимке собранного образа
- Имя ссылки может быть любым: значок берётся от папки `/Applications`, перетаскивание идёт в неё

**Применение:** ссылка названа «Программы», как в тексте окна «Перетащите VibeRDP в «Программы»» и как говорит интерфейс по умолчанию; в `layout.py` имя ссылки передаётся параметром, чтобы раскладка и проверка знали его.

## Иконка приложения

**Суть:**
- Каталог ресурсов с `AppIcon.appiconset` и `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon` дают в бандле `Contents/Resources/AppIcon.icns` и ключ `CFBundleIconName` в `Info.plist`
- Без иконки приложение в Finder, Dock и окне установки показывается общим значком

**Применение:** проверка бандла в `build-client.sh` требует оба признака; PNG всех размеров рисует `render-icon.sh` из SVG и они коммитятся, так CI не нужен `rsvg-convert`.

## Замер посадки подписей

**Суть:** на снимке окна по номеру окна (`screencapture -l`) `checkCentering.py` дал сдвиг подписи 1,5 точки для «VibeRDP» и 0,5 точки для «Программы» относительно светлой части «экрана» — в пределах, где правка не нужна.

**Не проверено:** вид окна при показе скрытых файлов (⌘⇧.) — папка фона отнесена за нижний край по правилу навыка, глазами не смотрели.
