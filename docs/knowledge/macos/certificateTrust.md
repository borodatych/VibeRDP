# macOS: проверка сертификата сервера

Проверено 2026-09-24 на macOS 26.6.2 пробными программами и тестами `client-macos/Tests/CertificateTrustTests.swift`.
Модель доверия клиента — [decisions.md](../../decisions.md), раздел 14; что отдаёт ядро — [freerdp/clientLifecycle.md](../freerdp/clientLifecycle.md).

## Какой код возвращает SecTrust

**Суть:**
- `SecTrustEvaluateWithError` сообщает один код — самую значимую из проблем цепочки
- Для недоверенного самоподписанного сертификата это всегда `errSecNotTrusted` (-67843): и при чужом имени, и после истечения срока, и до его начала — дата задавалась через `SecTrustSetVerifyDate`
- Коды `errSecHostNameMismatch` (-67602) и `errSecCertificateExpired` (-67818) видны только у цепочки, которой macOS доверяет, например выданной корпоративным центром из связки ключей
- Предельный срок действия серверного сертификата macOS проверяет раньше доверия: самоподписанный сертификат на 100 лет получил `errSecCertificateValidityPeriodTooLong` (-67901), а не -67843

**Применение:**
- Для самоподписанного сертификата Windows диалог называет одну причину — недоверенного издателя; имя и срок пользователь сверяет по отпечатку
- Тестовая фикстура — сертификат на год, как у Windows; тест не зависит от даты, потому что для недоверенной цепочки ответ тот же и после истечения срока
- Коды, у которых нет своей причины в интерфейсе, показываются числом: `TrustProblem.other`

## Скорость оценки

**Суть:**
- Отдельной программой оценка самоподписанного сертификата занимает 0,01 с — с сетевыми запросами SecTrust и без них (`SecTrustSetNetworkFetchAllowed`)
- В свежесобранном приложении первая оценка однажды заняла 64 с; повтор того же теста — 0,05 с; _причина не установлена_, похоже на первый запрос к `trustd` от новой ad-hoc-подписи

**Применение:** оценка идёт вне главного потока (`Task.detached` в `SessionController`), окно показывает «Подключение…», а кнопка «Отключиться» снимает ожидание в любой момент.

## Отпечаток

**Суть:** отпечаток — SHA-256 DER-кодировки сертификата сервера, шестнадцатеричный через двоеточие: так его печатают `openssl x509 -fingerprint -sha256` и оснастка сертификатов Windows; значение фикстуры сверено с выводом `openssl`.

**Применение:** запомненные отпечатки лежат в `UserDefaults` под ключом `trustedCertificates` — словарь «хост:порт → отпечаток», хост в нижнем регистре, IPv6 — в квадратных скобках.

**Источники:**
- Заголовки SDK 27: `Security.framework/Headers/SecBase.h` (коды -67602, -67818, -67843, -67901), `SecTrust.h`
- `client-macos/Session/CertificateTrust.swift`, `client-macos/Tests/CertificateTrustTests.swift`, `client-macos/Tests/Fixtures.swift`
