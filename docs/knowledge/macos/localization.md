# macOS: языки приложения

Проверено 2026-09-25 на macOS 26, задача 1.9; тесты — `LanguagesTests`, гейт — `client-macos/scripts/check-localization.py`.
Механизм — правило семейства «Локализация: как строить», решение 22 в [decisions.md](../../decisions.md), спека файла — [manuals/langSpec.md](../../manuals/langSpec.md).

## Строки, которые macOS показывает сама

**Суть:**
- Вопрос о доступе к локальной сети цитирует `NSLocalNetworkUsageDescription`, а Finder называет тип файла по `CFBundleTypeName` и `UTTypeDescription` — всё это macOS читает из бандла до запуска приложения
- Переводы этих строк — `<язык>.lproj/InfoPlist.strings` в бандле: ключ системной строки — её имя, а для типа документа — само значение из Info.plist
- Язык разработки задаёт, что показывать, если перевода нет: у VibeRDP это русский (`developmentLanguage: ru` в `project.yml`)

**Применение:** `client-macos/Localized/en.lproj/InfoPlist.strings`; тест проверяет, что бандл несёт английский файл.

## Язык тестового прогона

**Суть:**
- Тесты работают внутри запущенного приложения, а оно при старте выбирает язык по системе: на Маке с английской системой — английский файл, на русской — вшитый русский
- Запуск приложения засевает `~/VibeRDP/lang/` — и тестовый тоже

**Применение:** тесты сравнивают строки через `Localization.text`, а не русскими литералами; то, что проверяет саму базу, берёт `TextKey.baseText` и `Localization.fill` — так результат не зависит от языка машины.

## Каталог и главный актор

**Суть:** `Localization.text` зовут и вне главного актора, поэтому каталог в памяти защищён `OSAllocatedUnfairLock` (macOS 13+), а не привязан к `@MainActor`.

## Гейт: исходники на съёмном томе

**Суть:** репозиторий и кэш лежат на `/Volumes/Storage`, который macOS считает съёмным, — приложение, читающее чужие файлы оттуда, может упереться в системный вопрос о доступе — [removableVolumePrivacy.md](removableVolumePrivacy.md).

**Применение:** проверка исходников — отдельный скрипт на Python при сборке, а не тест внутри приложения.
