# macOS: приватность буфера обмена

## Запрос разрешения на программное чтение буфера

**Контекст:** боль №1 из [idea.md](../../idea.md) — буфер Mac → Windows; задача 2.1.

**Суть:**
- Apple анонсировала: система предупреждает пользователя, когда приложение программно читает общий буфер, а чтение не вызвано действием пользователя на элементе интерфейса, который система считает связанным со вставкой (релиз-ноты macOS 15.4)
- С macOS 15.4 у `NSPasteboard` есть свойство `accessBehavior` со значениями `default`, `ask`, `alwaysAllow`, `alwaysDeny`
- По заголовку SDK `default` для общего буфера означает «спрашивать при программном доступе»; после первого запроса значение само становится `ask`, и приложение появляется в Системных настройках, где пользователь выбирает «спрашивать», «разрешать всегда» или «запрещать всегда»
- Доступ, который одновременно инициирован пользователем и связан со вставкой, разрешён всегда — даже при `alwaysDeny`
- Методы `detectPatternsForPatterns:`, `detectValuesForPatterns:` и `detectMetadataForTypes:` у `NSPasteboard` и `NSPasteboardItem` работают без запроса, но отвечают только про шаблоны (ссылка, число, адрес и т. п.) и ограниченные метаданные, а не про список типов данных в буфере
- Включить поведение заранее для своего приложения: `defaults write <bundle id> EnablePasteboardPrivacyDeveloperPreview -bool yes`
- По сторонним источникам на середину 2026 в macOS 26 механизм по умолчанию не включён

**Применение:**
- Путь Mac → Win: данные буфера читаются по Format Data Request, когда пользователь вставляет в Windows-приложении, — это программное чтение, а не команда «Вставить» нашего интерфейса
- Если Apple включит механизм по умолчанию, вставка в Windows упрётся в запрос разрешения — удар прямо по боли №1
- На 2.1: прогнать клиент с флагом developer preview; выяснить, какие вызовы нашего пути вызывают запрос; читать `accessBehavior` и при «спрашивать» или «запрещать» показывать пользователю, где разрешить VibeRDP доступ

**Не проверено:**
- Вызывают ли запрос `changeCount` и `types` — от этого зависит, можно ли анонсировать форматы в Windows без запроса
- Включён ли механизм на реальной macOS 26.6 без флага
