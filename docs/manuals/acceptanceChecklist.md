# ЧЕК-ЛИСТ ПРИЁМКИ v0.1: VIBERDP РЯДОМ С WINDOWS APP

Один проход оператора перед выпуском v0.1: всё ли работает на настоящем Windows и где VibeRDP лучше или хуже Windows App.
Подробные шаги по каждой возможности — в [liveChecks.md](liveChecks.md); здесь — порядок прохода, сравнение и форма итога.
Сравнение идёт на одном хосте, одной учётной записи и одной сети: иначе разница окажется разницей условий.

---

## 1. Подготовка

**Что нужно:**
- Мак с macOS 14 или новее; записать модель и версию macOS
- Хост Windows 10, 11 или Windows Server с удалённым рабочим столом; записать версию и сборку
- VibeRDP — образ `.dmg` из задачи 2.6 или артефакт `VibeRDP-app` из CI
- Windows App из App Store; записать версию: «Windows App» → «О программе»
- На Windows — Блокнот, WordPad или Word, Paint, Edge
- На Маке — TextEdit, Просмотр, Finder, Мониторинг системы

**Файлы для проверок на Маке:**
- Папка с парой файлов и вложенной папкой, один файл с русским именем
- Файл в 1 ГБ — команда в Терминале:
  ```bash
  mkfile 1g ~/Desktop/big.bin
  ```

**Первый запуск VibeRDP:**
Сборка без подписи Apple, и macOS при двойном щелчке скажет, что открыть её нельзя.
Открыть правой кнопкой → «Открыть», затем подтвердить «Открыть» в диалоге.

**Журнал — на случай дефекта:**
VibeRDP сам пишет журнал движка и приложения в `~/VibeRDP/logs/`, по файлу на запуск; пока VibeRDP в разработке, журнал включён по умолчанию.
Где он, что в нём и как его прислать — [diagnostics.md](diagnostics.md).

## 3. Сравнение с Windows App

Каждый сценарий — сначала в VibeRDP, потом в Windows App, на том же хосте.
Колонка «Windows App» заполняется тем, что увидено, а не тем, что известно из описаний.
Итог — одно из трёх: **лучше**, **так же**, **хуже** — про VibeRDP.

### С1. Копирование на Маке, пока окно удалённого стола впереди

Главная боль Windows App: скопированное на Маке не доходит до Windows, пока не переключишь фокус туда-обратно — [idea.md](../idea.md), раздел 1.

**Шаги:**
1. В TextEdit скопировать слово «первое», перейти в окно удалённого стола, вставить в Блокнот
2. В Терминале Мака запустить команду, сразу перейти в окно удалённого стола и больше его не покидать:
   ```bash
   sleep 5; echo "второе $(date +%s)" | pbcopy
   ```
3. Через 6 секунд, не уходя из окна, вставить в Блокнот

**VibeRDP, ожидается:** на шаге 3 вставляется «второе …» — буфер опрашивается каждые 250 мс
**Windows App:** записать, что вставилось на шаге 3

### С2. Копирование в Windows и вставка на Маке

**Шаги:**
1. В Блокноте скопировать строку с русским текстом и эмодзи
2. Сразу перейти в TextEdit и вставить

**VibeRDP, ожидается:** строка та же, переводы строк на месте
**Windows App:** записать

### С3. Оформленный текст

**Шаги:** liveChecks, раздел 13, шаги 1 и 4 — Edge → TextEdit и TextEdit → WordPad

**VibeRDP, ожидается:** жирный, курсив, ссылки и русский текст на месте
**Windows App:** записать

### С4. Картинки

**Шаги:** liveChecks, раздел 14, шаги 2 и 4 — снимок окна Мака → Word и Paint, Paint → Просмотр

**VibeRDP, ожидается:** в Word прозрачный фон, в Paint белый, в Просмотре картинка не отражена
**Windows App:** записать

### С5. Файлы

**Шаги:**
1. Finder → Проводник: папка с вложенной папкой и файлом с русским именем
2. Проводник → Finder: та же папка
3. Проводник → Finder: `big.bin` в 1 ГБ; засечь время от ⌘V до появления файла

**VibeRDP, ожидается:** папки и имена на месте в обе стороны; на шаге 3 — окно с прогрессом и кнопкой «Отменить»
**Windows App:** записать; на шаге 3 — время и как показан прогресс

### С6. Клавиатура

**Шаги:**
1. ⌘C, ⌘V, ⌘Z, ⌘A в Блокноте
2. Сменить раскладку на Маке на русскую, набрать в Блокноте слово; вернуть английскую, набрать слово

**VibeRDP, ожидается:** шаг 1 работает как Ctrl в Windows; на шаге 2 раскладка Windows за Маком _не следует_ — синхронизация раскладки в v0.1 не входит, это задача 3.3
**Windows App:** записать оба шага

### С7. Полный экран и пространства

**Шаги:** развернуть на весь экран, переключиться жестом на другое пространство и обратно, выйти из полного экрана

**VibeRDP, ожидается:** изображение не пропадает и не растягивается, ввод идёт в Windows после возврата
**Windows App:** записать

### С8. Сон Мака и обрыв сети

**Шаги:**
1. Закрыть крышку на 2 минуты, открыть
2. Выключить Wi-Fi на 10 секунд, включить

**VibeRDP, ожидается:** поверх стола «Связь с … прервалась — переподключение…» с номером попытки, затем тот же сеанс
**Windows App:** записать

### С9. Видео и нагрузка

**Шаги:**
1. В Edge на удалённом столе открыть видео 1080p на весь экран на минуту
2. В Мониторинге системы смотреть «% ЦП» у приложения клиента

**VibeRDP, ожидается:** видео плавное — H.264 декодирует VideoToolbox; записать «% ЦП»
**Windows App:** записать плавность и «% ЦП»

### С10. Вход через шлюз и по Kerberos

Только если в сети есть RD Gateway или домен.

**Шаги:** liveChecks, разделы 7 и 10

**VibeRDP, ожидается:** вход через шлюз и по Kerberos проходит
**Windows App:** записать

### С11. Импорт `.rdp`

**Шаги:** один и тот же `.rdp`, например выданный администратором, открыть в обоих клиентах

**VibeRDP, ожидается:** адрес, пользователь и шлюз перенесены — liveChecks, раздел 6
**Windows App:** записать, что перенеслось

### С12. Чего в v0.1 нет

Не дефекты, а список разрыва: что Windows App умеет, а VibeRDP ещё нет, — с задачей плана.

| Возможность | Задача VibeRDP | Windows App — записать, есть ли |
|---|---|---|
| Разрешение по размеру окна | 3.1 | |
| Несколько мониторов, Retina | 3.2 | |
| Синхронизация раскладки | 3.3 | |
| Звук | 3.4 | |
| Папки Мака в Windows | 3.5 | |
| Приложения Windows отдельными окнами | этапы 4–7 | |
| Принтеры, USB, смарт-карты | не цели v1, [idea.md](../idea.md), раздел 1 | |

## 5. Как описать дефект

**В описании:**
- Сценарий и шаг: «С5, шаг 3» или «liveChecks, раздел 14, шаг 2»
- Что ожидалось и что случилось, по строке на каждое
- Версии из шапки итога
- Журнал этого запуска из `~/VibeRDP/logs/` и время случая, если дефект про подключение, картинку или буфер — [diagnostics.md](diagnostics.md)

**Без:**
- Паролей, имён хостов и учётных записей рабочей сети — в журнале их заменить перед отправкой
