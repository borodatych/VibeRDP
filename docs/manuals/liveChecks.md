## 1. Подключение с NLA и сертификат (задача 1.1)

**Что нужно:**
- Windows 10 или 11 Pro, а лучше Windows Server с включённым удалённым рабочим столом
- Учётная запись с правом входа по RDP
- Сборка VibeRDP из `client-macos/scripts/build-client.sh` или артефакт `VibeRDP-app` из CI

**Шаги:**
1. Запустить VibeRDP, ввести имя компьютера в своей сети, пользователя и пароль, нажать «Подключиться»
   Ожидается при первом подключении: запрос macOS о доступе к локальной сети с текстом «VibeRDP подключается к компьютерам Windows в вашей сети по протоколу RDP.» — разрешить
   Затем: статус «Подключение к …» и диалог «Не удалось проверить подлинность …» — у Windows по умолчанию самоподписанный сертификат
2. Сверить SHA-256 в диалоге с отпечатком сертификата на хосте:
   PowerShell на хосте
   ```powershell
   Get-ChildItem Cert:\LocalMachine\"Remote Desktop" | ForEach-Object { [BitConverter]::ToString([Security.Cryptography.SHA256]::Create().ComputeHash($_.RawData)) }
   ```
   Ожидается: те же байты; PowerShell разделяет их дефисом, диалог — двоеточием
   _Команда агентом на Windows не запускалась_
3. Нажать «Подключиться», не отмечая «Запомнить сертификат»
   Ожидается: статус «Подключено к …»; изображения рабочего стола ещё нет, оно появится на задаче 1.2
4. Нажать «Отключиться», подключиться снова
   Ожидается: диалог появляется снова — сертификат не запомнен
5. Подключиться, отметить «Запомнить сертификат», принять; отключиться и подключиться снова
   Ожидается: диалога нет, сразу «Подключено к …»
6. Ввести неверный пароль
   Ожидается: «Неверное имя пользователя или пароль» с кодом движка в скобках
7. Ввести пользователя в виде `ДОМЕН\пользователь`, затем `пользователь@домен`
   Ожидается: оба варианта подключаются
8. Нажать «Отмена» в диалоге сертификата
   Ожидается: «Подключение к … отменено: сертификат не принят»
9. Открыть диалог сертификата и, не отвечая, завершить программу — ⌘Q
   Ожидается: программа закрывается сразу, без зависания
10. Сменить сертификат на хосте, пересоздав самоподписанный — из консоли хоста, не по RDP: перезапуск службы рвёт все RDP-сессии
    ```powershell
    Get-ChildItem Cert:\LocalMachine\"Remote Desktop" | Remove-Item; Restart-Service TermService -Force
    ```
    _Команда агентом не запускалась: Windows создаёт новый самоподписанный сертификат при старте службы — проверить, что отпечаток из шага 2 сменился_
    Подключиться к хосту из шага 5
    Ожидается: диалог «Сертификат … изменился», первой стоит кнопка «Отмена»
11. Если есть хост с сертификатом корпоративного центра, которому доверяет Mac:
    Ожидается: подключение без диалога
