# ПРОВЕРКИ НА НАСТОЯЩЕМ WINDOWS-ХОСТЕ

Что проверяет оператор руками: у агента нет Windows-машины, а тесты доходят только до TLS-рукопожатия с фейковым сервером.
Каждая задача roadmap, которой нужен живой хост, добавляет сюда свой раздел.
Результат — строкой в конце раздела: дата, версия Windows, что прошло, что нет.
Порядок прохода перед выпуском и сравнение с Windows App — [acceptanceChecklist.md](acceptanceChecklist.md).

---

## 1. Подключение с NLA и сертификат (задача 1.1)

**Что нужно:**
- Windows 10 или 11 Pro, а лучше Windows Server с включённым удалённым рабочим столом
- Учётная запись с правом входа по RDP
- Сборка VibeRDP из `client-macos/scripts/build-client.sh` или артефакт `VibeRDP-app` из CI

**Шаги:**
1. Запустить VibeRDP, ввести имя компьютера в своей сети, пользователя и пароль, нажать «Подключиться»
   Ожидается при первом подключении: запрос macOS о доступе к локальной сети с текстом «VibeRDP подключается к компьютерам Windows в вашей сети по протоколу RDP.» — разрешить
   Затем: статус «Подключение к …» и диалог «Не удалось проверить подлинность …» — у Windows по умолчанию самоподписанный сертификат
2. Сверить SHA-256 в диалоге с отпечатком сертификата на хосте:
   PowerShell на хосте
   ```powershell
   Get-ChildItem Cert:\LocalMachine\"Remote Desktop" | ForEach-Object { [BitConverter]::ToString([Security.Cryptography.SHA256]::Create().ComputeHash($_.RawData)) }
   ```
   Ожидается: те же байты; PowerShell разделяет их дефисом, диалог — двоеточием
   _Команда агентом на Windows не запускалась_
3. Нажать «Подключиться», не отмечая «Запомнить сертификат»
   Ожидается: окно показывает рабочий стол Windows — подробно в разделе 2
4. Меню «Файл» → «Отключиться», подключиться снова
   Ожидается: диалог появляется снова — сертификат не запомнен
5. Подключиться, отметить «Запомнить сертификат», принять; отключиться через меню «Файл» и подключиться снова
   Ожидается: диалога нет, сразу рабочий стол
6. Ввести неверный пароль
   Ожидается: «Неверное имя пользователя или пароль» с кодом движка в скобках
7. Ввести пользователя в виде `ДОМЕН\пользователь`, затем `пользователь@домен`
   Ожидается: оба варианта подключаются
8. Нажать «Отмена» в диалоге сертификата
   Ожидается: «Подключение к … отменено: сертификат не принят»
9. Открыть диалог сертификата и, не отвечая, завершить программу — ⌘Q
   Ожидается: программа закрывается сразу, без зависания
10. Сменить сертификат на хосте, пересоздав самоподписанный — из консоли хоста, не по RDP: перезапуск службы рвёт все RDP-сессии
    ```powershell
    Get-ChildItem Cert:\LocalMachine\"Remote Desktop" | Remove-Item; Restart-Service TermService -Force
    ```
    _Команда агентом не запускалась: Windows создаёт новый самоподписанный сертификат при старте службы — проверить, что отпечаток из шага 2 сменился_
    Подключиться к хосту из шага 5
    Ожидается: диалог «Сертификат … изменился», первой стоит кнопка «Отмена»
11. Если есть хост с сертификатом корпоративного центра, которому доверяет Mac:
    Ожидается: подключение без диалога

**Результаты:**
- _ещё не проверялось_

## 2. Рабочий стол и полноэкранный режим (задача 1.2)

**Что нужно:**
- Хост и сборка из раздела 1
- Mac с экраном Retina; внешний монитор без Retina — по желанию

**Шаги:**
1. Подключиться, как в разделе 1
   Ожидается: после входа открывается отдельное окно сессии с названием подключения и рабочим столом Windows; окно подключений остаётся на месте и своего размера
   Цвета те же, что на самом хосте: синий фон остаётся синим, без бурого или оранжевого оттенка
   На Retina картинка резкая, пиксель в пиксель — раздел 16, шаг 5
2. Подождать, пока на хосте что-то сменится само, — например, минута на часах панели задач
   Ожидается: изменение видно в окне без задержки
   _Клавиатура в удалённый рабочий стол пока не передаётся — задача 1.4; мышь — раздел 3_
3. Потянуть за край окна сессии: сделать его шире, затем выше
   Ожидается: пока край движется, рабочий стол вписан целиком с чёрными полями; после остановки Windows перестраивает рабочий стол под окно — подробно в разделе 16
4. Меню «Окно» → «Во весь экран»
   Ожидается: окно уходит на свой полноэкранный стол, рабочий стол вписан с полями; в меню у пункта показано сочетание fn-F
5. Нажать fn-F
   Ожидается: окно возвращается из полноэкранного режима
6. Перетащить окно на внешний монитор без Retina и обратно, если он есть
   Ожидается: картинка не пропадает и остаётся вписанной
7. Меню «Файл» → «Отключиться»
   Ожидается: окно сессии закрывается, окно подключений выходит вперёд со статусом «Отключено от …»; без сессии пункт «Отключиться» неактивен
8. Подключиться снова и нажать кнопку «Отключиться» в заголовке окна сессии, затем ещё раз подключиться и нажать красную кнопку окна
   Ожидается: оба раза сессия отключается сразу, без вопроса, окно сессии закрывается
9. Развернуть окно сессии на весь экран, отключиться
   Ожидается: окно подключений того же размера, что до подключения; следующая сессия открывается развёрнутой — окно помнит место и размер

## 3. Мышь, прокрутка и курсор (задача 1.3)

**Что нужно:**
- Хост и сборка из раздела 1
- Трекпад Mac; мышь с колесом и боковыми кнопками — по желанию

**Шаги:**
1. Подключиться и поводить мышью по рабочему столу
   Ожидается: курсор Windows следует за мышью без запаздывания; над текстом он становится текстовым, над краем окна Windows — стрелкой изменения размера, над ссылкой в браузере — рукой
2. Двойной щелчок по значку «Корзина»
   Ожидается: окно корзины открывается
3. Правый щелчок по рабочему столу, затем щелчок двумя пальцами на трекпаде
   Ожидается: оба раза открывается контекстное меню Windows
4. Перетащить значок по рабочему столу
   Ожидается: значок едет за мышью и остаётся там, где его отпустили
5. Средняя кнопка по вкладке браузера и боковые кнопки «назад» и «вперёд» в Проводнике, если такая мышь есть
   Ожидается: вкладка закрывается, Проводник переходит назад и вперёд
6. Прокрутить колесом длинный документ, по одному щелчку
   Ожидается: щелчок колеса листает столько же, сколько на самом Windows, — по умолчанию три строки
7. Прокрутить документ двумя пальцами на трекпаде, медленно и резким жестом
   Ожидается: медленное движение тоже листает, резкий жест продолжается по инерции; направление то же, что в программах Mac
   Скорость сравнить с прокруткой на Mac; если заметно быстрее или медленнее, записать во сколько раз — по этому числу подбирается `WheelAccumulator.unitsPerPoint`
8. Прокрутить трекпадом вбок широкую таблицу
   Ожидается: таблица едет в ту же сторону, что и в программах Mac
9. Переключиться в другое приложение и щёлкнуть по рабочему столу в окне VibeRDP
   Ожидается: окно становится активным, и тот же щелчок доходит до Windows
10. Включить видео во весь экран в Windows и не трогать мышь
    Ожидается: курсор над окном прячется, при движении мыши появляется
11. Меню «Окно» → «Во весь экран» и снова навести курсор на текст
    Ожидается: курсор того же размера, что элементы Windows на экране, а точка щелчка — на кончике стрелки

**Результаты:**
- _ещё не проверялось_

## 4. Клавиатура (задача 1.4)

**Что нужно:**
- Хост и сборка из раздела 1
- В Windows — русская и английская раскладки; переключаются они в Windows, синхронизация с Маком — задача 3.3
- Настройки VibeRDP по умолчанию: меню VibeRDP → «Настройки…» → «Вернуть по умолчанию»

**Шаги:**
1. Подключиться, открыть Блокнот и набрать строку с цифрами, знаками и Shift
   Ожидается: в Блокноте ровно набранное, в раскладке Windows; клавиши не повторяются лишний раз и не залипают
2. Удерживать букву две секунды
   Ожидается: буква повторяется, как на самом Windows, и перестаёт, как только клавишу отпустили
3. Выделить текст, ⌘C, перейти в конец, ⌘V; затем ⌘Z и ⌘A
   Ожидается: работает как Ctrl+C, Ctrl+V, Ctrl+Z и Ctrl+A
4. Нажать и отпустить правую ⌘; затем правая ⌘ + E
   Ожидается: открывается меню «Пуск», затем Проводник
5. Переключить раскладку Windows сочетанием ⌥⇧ или правая ⌘ + Пробел и набрать слово
   Ожидается: раскладка переключается, текст — на другом языке
6. Включить Caps Lock на Маке, набрать слово; выключить, набрать ещё одно
   Ожидается: первое слово заглавными, второе строчными; индикатор Caps Lock в Windows, если он виден, совпадает с Маком
7. Набрать цифры на цифровом блоке, если он есть
   Ожидается: печатаются цифры, а не стрелки
8. Стрелки, fn + стрелки (Home, End, Page Up, Page Down), fn + ⌫ (Delete), F1–F12 с fn или без, как настроен Мак
   Ожидается: каждая клавиша делает то же, что на клавиатуре PC
9. ⌘W в браузере с двумя вкладками
   Ожидается: закрывается вкладка в Windows, окно VibeRDP остаётся
10. Зажать ⌘ и Shift, переключиться на другое приложение по ⌘Tab, отпустить клавиши там, вернуться и набрать букву
    Ожидается: буква строчная, Ctrl и Shift в Windows не залипли
11. ⌘H, затем вернуть VibeRDP; ⌘M, затем вернуть окно из Dock
    Ожидается: окно прячется и сворачивается, как у любого приложения Mac
12. ⌥⌘W
    Ожидается: сессия завершается, возвращается форма подключения
13. ⌘⌥ + fn + → (Ctrl+Alt+End)
    Ожидается: открывается экран безопасности Windows — замена Ctrl+Alt+Del в RDP
14. Настройки → «Как на PC», подключиться снова и нажать левую ⌘
    Ожидается: левая ⌘ открывает «Пуск», ⌘C больше не копирует
15. Клавиатура ISO (есть клавиша между левым Shift и Z): включить галочку в настройках, в английской раскладке Windows нажать клавишу слева от 1 и клавишу справа от левого Shift
    Ожидается: слева от 1 печатается `, справа от Shift — \ ; с выключенной галочкой — наоборот; записать, какой вариант верен

**Результаты:**

## 5. Подключения и пароли (задача 1.5)

**Что нужно:**
- Хост и сборка из раздела 1; на хосте включён NLA — так по умолчанию

**Шаги:**
1. «+», заполнить компьютер и пользователя, пароль оставить пустым, «Подключиться»
   Ожидается: VibeRDP спрашивает пароль; после ввода рабочий стол открывается
2. Отключиться, подключиться снова
   Ожидается: пароль больше не спрашивается; при первом чтении пароля macOS может спросить доступ к связке ключей — «Разрешать всегда»
3. Открыть «Связку ключей», найти «VibeRDP: <название>»
   Ожидается: запись есть, её учётная запись — длинный идентификатор
4. В вопросе о пароле ввести неверный пароль
   Ожидается: «Неверное имя пользователя или пароль», вопрос повторяется; верный пароль подключает, и в связке лежит верный
5. Снять «Запомнить пароль в связке ключей»
   Ожидается: запись в «Связке ключей» исчезла, следующее подключение снова спрашивает пароль
6. «Отмена» в вопросе о пароле
   Ожидается: подключение прекращается без сообщения об ошибке
7. Подключению выбрать «Клавиатура → Как на PC», подключиться, нажать левую ⌘
   Ожидается: открывается «Пуск»; у другого подключения ⌘C по-прежнему копирует
8. Удалить подключение кнопкой «−»
   Ожидается: и строка, и запись в «Связке ключей» исчезли
9. Закрыть и снова открыть VibeRDP
   Ожидается: подключения на месте в том же порядке

## 6. Импорт файлов .rdp (задача 1.6)

**Что нужно:**
- Файл .rdp, сохранённый Windows App на Маке или «Подключением к удалённому рабочему столу» (mstsc) на Windows: «Сохранить как»

**Шаги:**
1. «Файл → Импортировать файл .rdp…», выбрать файл
   Ожидается: в списке новое подключение с именем файла, компьютером, портом и пользователем из файла
2. Импортировать тот же файл ещё раз
   Ожидается: второго подключения нет, выбрано первое, статус «уже есть в списке»
3. В Finder: правая кнопка на файле → «Открыть в программе» → VibeRDP
   Ожидается: VibeRDP открывается, выбирает подключение и сразу подключается; пароль спрашивается
4. Файл с `alternate full address` (если есть) или с портом, отличным от 3389
   Ожидается: подключение идёт по альтернативному адресу и на указанный порт
5. На Маке с Windows App и сохранёнными в ней подключениями: «Файл → Импортировать из Windows App…» (задача 1.13)
   Ожидается: если macOS спросит о доступе к данным другого приложения — записать текст вопроса и разрешить; затем в списке подключения Windows App с названиями, пользователями и шлюзами, статус «Из Windows App добавлено подключений: N…»
6. Повторить шаг 5
   Ожидается: новых подключений нет, статус «добавлено подключений: 0, уже были в списке: N»
7. Подключиться к перенесённому
   Ожидается: VibeRDP спрашивает пароль — из Windows App он не переносится; после входа с «Запомнить» второй раз не спрашивает
8. Удалить все подключения VibeRDP
   Ожидается: в пустом списке кнопка «Перенести подключения из Windows App»; без Windows App кнопки и пункта меню нет

**Результаты:**

**Что нужно:**
- Компьютер за шлюзом удалённых рабочих столов: имя шлюза, имя компьютера во внутренней сети, учётная запись с правом подключаться через шлюз

**Шаги:**
1. Подключение с компьютером во внутренней сети и шлюзом, «Те же имя и пароль» включено, пароль не сохранён

4. Выключить «Те же имя и пароль», указать пользователя шлюза
   Ожидается: VibeRDP спрашивает пароль шлюза с его именем в заголовке, затем пароль компьютера; в «Связке ключей» две записи
5. Импортировать .rdp с `gatewayhostname` и `gatewayusagemethod:i:1`

## 8. Переподключение (задача 1.8)

**Что нужно:**
- Хост и сборка из раздела 1, Mac на Wi-Fi

**Шаги:**
1. Подключиться, открыть Блокнот, набрать строку; выключить Wi-Fi на 10 секунд и включить
   Ожидается: рабочий стол затемняется с надписью «переподключение» и номером попытки; после включения Wi-Fi сеанс возвращается, Блокнот с тем же текстом на месте
2. Во время переподключения нажать «Отключиться»
   Ожидается: попытки прекращаются, возвращается список подключений
3. Закрыть крышку Мака на минуту, открыть
   Ожидается: в течение нескольких секунд сеанс либо продолжается, либо проходит переподключение; рабочий стол не зависает на старой картинке
4. Закрыть крышку на полчаса, открыть
   Ожидается: переподключение к тому же сеансу, программы Windows на месте
5. В Windows: «Пуск» → выход из системы
   Ожидается: VibeRDP не переподключается, возвращается список подключений с причиной
6. Подключиться к тому же компьютеру с другого клиента под тем же пользователем
   Ожидается: VibeRDP не переподключается и объясняет, что сеанс заняли

## 9. Язык интерфейса (задача 1.9)

**Что нужно:**
- Сборка VibeRDP; на Маке можно сменить язык системы или только язык приложения в «Системные настройки → Основные → Язык и регион → Приложения»

**Шаги:**
1. Запустить VibeRDP, открыть в Finder `~/VibeRDP/lang/`
   Ожидается: там `en.json` и `example.jsonc`
2. «Настройки → Язык» → English, перезапустить VibeRDP
   Ожидается: меню, список подключений, окно входа и настройки — по-английски
3. Удалить `en.json` под работающим VibeRDP, перезапустить
   Ожидается: интерфейс по-английски до перезапуска; после — по-русски, а `en.json` снова в папке
4. «Создать файл для правки», поменять в `ru.json` значение `menu.file.disconnect`, выбрать русский, перезапустить

4. Подключение по адресу IP вместо имени
