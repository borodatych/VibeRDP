# ПРОВЕРКИ НА НАСТОЯЩЕМ WINDOWS-ХОСТЕ

Что проверяет оператор руками: у агента нет Windows-машины, а тесты доходят только до TLS-рукопожатия с фейковым сервером.
Каждая задача roadmap, которой нужен живой хост, добавляет сюда свой раздел.
Результат — строкой в конце раздела: дата, версия Windows, что прошло, что нет.

---

## 1. Подключение с NLA и сертификат (задача 1.1)

**Что нужно:**
- Windows 10 или 11 Pro, а лучше Windows Server с включённым удалённым рабочим столом
- Учётная запись с правом входа по RDP
- Сборка VibeRDP из `client-macos/scripts/build-client.sh` или артефакт `VibeRDP-app` из CI

**Шаги:**
1. Запустить VibeRDP, ввести имя компьютера в своей сети, пользователя и пароль, нажать «Подключиться»
   Ожидается при первом подключении: запрос macOS о доступе к локальной сети с текстом «VibeRDP подключается к компьютерам Windows в вашей сети по протоколу RDP.» — разрешить
   Затем: статус «Подключение к …» и диалог «Не удалось проверить подлинность …» — у Windows по умолчанию самоподписанный сертификат
2. Сверить SHA-256 в диалоге с отпечатком сертификата на хосте:
   PowerShell на хосте
   ```powershell
   Get-ChildItem Cert:\LocalMachine\"Remote Desktop" | ForEach-Object { [BitConverter]::ToString([Security.Cryptography.SHA256]::Create().ComputeHash($_.RawData)) }
   ```
   Ожидается: те же байты; PowerShell разделяет их дефисом, диалог — двоеточием
   _Команда агентом на Windows не запускалась_
3. Нажать «Подключиться», не отмечая «Запомнить сертификат»
   Ожидается: окно показывает рабочий стол Windows — подробно в разделе 2
4. Меню «Файл» → «Отключиться», подключиться снова
   Ожидается: диалог появляется снова — сертификат не запомнен
5. Подключиться, отметить «Запомнить сертификат», принять; отключиться через меню «Файл» и подключиться снова
   Ожидается: диалога нет, сразу рабочий стол
6. Ввести неверный пароль
   Ожидается: «Неверное имя пользователя или пароль» с кодом движка в скобках
7. Ввести пользователя в виде `ДОМЕН\пользователь`, затем `пользователь@домен`
   Ожидается: оба варианта подключаются
8. Нажать «Отмена» в диалоге сертификата
   Ожидается: «Подключение к … отменено: сертификат не принят»
9. Открыть диалог сертификата и, не отвечая, завершить программу — ⌘Q
   Ожидается: программа закрывается сразу, без зависания
10. Сменить сертификат на хосте, пересоздав самоподписанный — из консоли хоста, не по RDP: перезапуск службы рвёт все RDP-сессии
    ```powershell
    Get-ChildItem Cert:\LocalMachine\"Remote Desktop" | Remove-Item; Restart-Service TermService -Force
    ```
    _Команда агентом не запускалась: Windows создаёт новый самоподписанный сертификат при старте службы — проверить, что отпечаток из шага 2 сменился_
    Подключиться к хосту из шага 5
    Ожидается: диалог «Сертификат … изменился», первой стоит кнопка «Отмена»
11. Если есть хост с сертификатом корпоративного центра, которому доверяет Mac:
    Ожидается: подключение без диалога

**Результаты:**
- _ещё не проверялось_

## 2. Рабочий стол и полноэкранный режим (задача 1.2)

**Что нужно:**
- Хост и сборка из раздела 1
- Mac с экраном Retina; внешний монитор без Retina — по желанию

**Шаги:**
1. Подключиться, как в разделе 1
   Ожидается: окно показывает рабочий стол Windows, в подзаголовке окна — имя компьютера
   Цвета те же, что на самом хосте: синий фон остаётся синим, без бурого или оранжевого оттенка
   На Retina картинка пока растянута вдвое и слегка мягкая — пиксель в пиксель придёт с задачей 3.2
2. Подождать, пока на хосте что-то сменится само, — например, минута на часах панели задач
   Ожидается: изменение видно в окне без задержки
   _Мышь и клавиатура в удалённый рабочий стол пока не передаются — задачи 1.3 и 1.4_
3. Потянуть за край окна: сделать его шире, затем выше
   Ожидается: рабочий стол вписан целиком, пропорции сохранены, по бокам или сверху и снизу — чёрные поля; размер рабочего стола на сервере не меняется — это задача 3.1
4. Меню «Окно» → «Во весь экран»
   Ожидается: окно уходит на свой полноэкранный стол, рабочий стол вписан с полями; в меню у пункта показано сочетание fn-F
5. Нажать fn-F
   Ожидается: окно возвращается из полноэкранного режима
6. Перетащить окно на внешний монитор без Retina и обратно, если он есть
   Ожидается: картинка не пропадает и остаётся вписанной
7. Меню «Файл» → «Отключиться»
   Ожидается: рабочий стол пропадает, форма возвращается со статусом «Отключено от …», подзаголовок окна пуст; без сессии пункт «Отключиться» неактивен
8. Подключиться снова и закрыть окно — ⌘W
   Ожидается: VibeRDP завершается сразу, без зависания

_Смену размера рабочего стола самим сервером посреди сессии проверит задача 3.1: там размер меняет клиент через канал disp, и сервер отвечает тем же путём — тестом на живом сервере этот путь ещё не пройден_

**Результаты:**
- _ещё не проверялось_
