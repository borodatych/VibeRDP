# ХЕЛПЕР SEAM НА WINDOWS

Хелпер — маленькая программа `vibe-seam-helper.exe` на удалённой Windows.
Она сообщает VibeRDP об окнах Windows и выполняет его команды: без неё режим Seam не включается, и VibeRDP остаётся в режиме Desktop.
Права администратора не нужны ни для установки, ни для работы.

---

## 1. Где взять

Файл собирает CI проекта на каждый push: артефакт `vibe-seam-helper` в запуске workflow «CI» на GitHub.
Своей сборки на Маке нет: exe линкуется только на Windows.

---

## 2. Установка

1. Скопировать `vibe-seam-helper.exe` на удалённую Windows, например через общую папку Мака в сессии VibeRDP
2. Запустить его из командной строки или ярлыком с параметром:
   `vibe-seam-helper.exe --install`
3. Окно сообщит, что хелпер установлен и запущен, и покажет путь

Что делает установка:
- Копирует exe в `%LOCALAPPDATA%\VibeRDP\vibe-seam-helper.exe`
- Кладёт ярлык «VibeRDP Seam» в папку автозагрузки пользователя (`shell:startup`), поэтому хелпер стартует при каждом входе в Windows
- Запускает установленную копию

Повторная установка поверх старой сначала останавливает запущенный хелпер, потом заменяет файл: так обновляется версия.

Язык сообщений установщика — русский; другой задаётся при установке, `vibe-seam-helper.exe --install --language en`, и запоминается.
Свой язык кладётся файлом в `%LOCALAPPDATA%\VibeRDP\lang\` — формат в [langSpec.md](langSpec.md), раздел 7.

---

## 3. Удаление

1. Запустить любую копию exe с параметром:
   `vibe-seam-helper.exe --uninstall`
2. Хелпер остановится, ярлык из автозагрузки и файл в `%LOCALAPPDATA%\VibeRDP` удалятся

Если удаление запустили из самого установленного файла, он сам себя не удалит: окно назовёт путь, и файл удаляется вручную.

---

## 4. Как понять, что он работает

- В «Диспетчере задач» на вкладке «Подробности» есть процесс `vibe-seam-helper.exe`; окна у него нет
- Журнал — `%LOCALAPPDATA%\VibeRDP\seam-helper.log`, начинается заново при каждом запуске
- Пока VibeRDP не подключён, в журнале строка `channel not available`: это обычное состояние, хелпер ждёт и пробует снова
- Второй запуск в той же сессии ничего не делает: работает одна копия на сессию

---

## 5. Если не запускается

- **AppLocker:** правила по умолчанию разрешают программы только из `Windows` и `Program Files`; установка скажет, что файл скопирован, но не запустился — нужен администратор хоста
- Другие причины — в журнале из раздела 4
