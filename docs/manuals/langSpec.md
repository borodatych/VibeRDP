# ФОРМАТ ЯЗЫКОВОГО ФАЙЛА VIBERDP

> **Скопируйте этот файл целиком своей языковой модели и попросите собрать перевод VibeRDP на нужный язык.**
> Здесь есть всё, что для этого нужно: где лежат файлы, формат, правила и где взять полный список ключей.
> Ходить в интернет и читать исходники не требуется.

---

## 1. Что это такое

VibeRDP говорит по-русски «из коробки»: русский каталог вкомпилирован в приложение, удалить его нельзя.
Любой другой язык — обычный файл JSON в папке `~/VibeRDP/lang/`.
Положили файл — язык появился в «Настройки → Язык» после перезапуска, удалили — исчез.
Немецкий, латынь, эльфийский, внутренний жаргон команды: приложению всё равно.

---

## 2. Папка и файлы

```
~/VibeRDP/lang/
├── en.json          ← кладётся приложением при запуске, если его нет
├── example.jsonc    ← образец с комментариями, тоже кладётся сам
├── de.json          ← вы добавили немецкий
└── ru.json          ← необязательный: правит вшитый русский
```

- **Имя файла — код языка.** `de.json` — язык `de`. Латиница, без пробелов, расширение строго `.json`
- **`.jsonc` приложение не читает.** Образец назван так нарочно: в нём комментарии, а JSON их не допускает
- **`en.json` можно менять.** Изменённый файл приложение не перезапишет; удалённый — положит заново
- **`ru.json` — не второй русский, а правка вшитого.** Его создаёт кнопка «Настройки → Язык → Создать файл для правки»: там полный русский каталог, дальше он ваш
- Правка `ru.json` действует в любом языке: переименованная по-русски кнопка останется такой и в немецком, если немецкий не перевёл её сам

## 3. Как устроен файл

Плоский объект JSON: ключ → строка.
Вложенности нет.

```json
{
  "$name": "Deutsch",

  "menu.file.disconnect": "Trennen",
  "connection.action.connect": "Verbinden",
  "connection.status.connecting": "Verbindung mit {host} wird hergestellt…",
  "connection.reconnecting.attempt": "Versuch {attempt} von {count}"
}
```

**Правила — все пять:**
1. **`$name` — как язык называется на самом себе.** Так он покажется в списке: `Deutsch`, а не «Немецкий». Ключи, которые начинаются с `$`, служебные и в интерфейс не попадают
2. **Ключи слева не трогать.** По ним приложение находит строку; `connection.action.connect` читается как «подключение → действие → подключиться», но разбирать его не нужно
3. **Переводить всё сразу не обязательно.** Чего нет в файле, покажется по-русски — или так, как исправлено в `ru.json`. Десять переведённых строк — уже рабочий язык
4. **`{имя}` в фигурных скобках — подстановка.** Приложение подставит туда значение: адрес компьютера, число, имя файла. Скобку можно передвинуть в любое место фразы, но **переименовывать нельзя**: `{host}` подставится, `{хост}` останется на экране буквами
5. **Только строки.** Число, `true`, массив вместо строки приложение пропустит

Значки клавиш — `⌘`, `⌃`, `⌥`, `⇧`, `⎋`, `⌫` — оставляйте как есть: так клавиши подписаны на клавиатуре Мака.
Названия клавиш Windows — `Ctrl`, `Alt`, `Windows` — тоже.

## 4. Полный список ключей

Получить его на диск:
- **«Настройки → Язык → Создать файл для правки»** — приложение запишет `~/VibeRDP/lang/ru.json` со всеми ключами и русскими значениями
- Или взять `~/VibeRDP/lang/en.json` — английский перевод всех ключей

Дальше — переведите значения в копии и сохраните под своим кодом, например `de.json`, или отдайте файл языковой модели вместе с этой спекой.

Разделы ключей, чтобы понимать, где строка видна:

| Префикс | Где видно |
|---|---|
| `menu.` | меню приложения, «Файл» и «Окно» |
| `connections.`, `profile.` | главное окно: список подключений и настройки выбранного |
| `connection.` | статусы и ошибки подключения, заглушка переподключения |
| `credentials.` | окно входа: имя пользователя и пароль |
| `certificate.` | вопрос о сертификате сервера |
| `gateway.` | сообщения шлюза удалённых рабочих столов |
| `settings.`, `shortcut.` | окно «Настройки»: клавиатура, сочетания, язык |
| `language.` | имя вшитого языка в списке — пишется на нём самом, не переводится |

---

## 5. Когда что читается

- **Папка читается при каждом запуске.** Добавили файл — перезапустите VibeRDP, язык появится в списке
- **Прочитанное живёт в памяти.** Менять и удалять файлы под работающим приложением безопасно: до перезапуска ничего не изменится
- **Выбранный язык, которого больше нет, не залипает:** приложение берёт язык системы, а если и его файла нет — вшитый русский; пропавший язык исчезает из списка
- **«Как в системе»** берёт первый язык из системных настроек Мака, для которого есть файл: для `de-AT` подойдёт `de.json`
- **Битый JSON ничего не роняет:** такой файл пропускается, остальные языки на месте

Строки, которые показывает сама macOS до запуска приложения — вопрос о доступе к локальной сети, название типа файлов `.rdp` в Finder, — живут в самом приложении, а не в этой папке.

---

## 6. Проверка перед тем, как отдать перевод

1. Файл называется кодом языка и лежит в `~/VibeRDP/lang/`
2. Это валидный JSON: без комментариев и висящих запятых
3. `$name` — на самом языке
4. Подстановки `{…}` уцелели во всех строках, где были, с теми же именами
5. VibeRDP перезапущен, язык виден в «Настройки → Язык», после выбора и ещё одного перезапуска интерфейс говорит на нём
