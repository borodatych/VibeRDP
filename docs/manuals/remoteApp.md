# REMOTEAPP: КАК ВКЛЮЧИТЬ НА WINDOWS

Инструкция для того, у кого есть права администратора на компьютере Windows.
С RemoteApp окна программ приходят в VibeRDP по протоколу RDP сами, без хелпера на Windows.
Без прав администратора RemoteApp не включить — тогда работает [хелпер](seamHelper.md), он прав не требует.

_Шаги взяты из документации Microsoft и на живой машине с VibeRDP ещё не проверялись._

---

## 1. Что нужно

- Windows 10 или 11 Pro, Enterprise или Education, либо Windows Server — в редакциях Home сервера RDP нет вовсе
- Удалённый рабочий стол на этом компьютере уже работает: VibeRDP подключается к нему обычным рабочим столом
- VibeRDP запускает через RemoteApp «Проводник» (`explorer.exe`), а из него — остальное; поэтому Windows должна разрешить запуск программ не из списка

---

## 2. Windows 10 и 11

1. Открыть PowerShell от имени администратора
2. Разрешить RemoteApp запускать программы не из списка:
   `New-ItemProperty -Path 'HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Terminal Server\TSAppAllowList' -Name fDisabledAllowList -PropertyType DWord -Value 1 -Force`
3. Перезагрузка не нужна

Отменить — то же значение `0`:
`Set-ItemProperty -Path 'HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Terminal Server\TSAppAllowList' -Name fDisabledAllowList -Value 0`

---

## 3. Windows Server с ролью узла сеансов

Либо тот же ключ реестра из раздела 2, либо групповая политика:
«Конфигурация компьютера → Административные шаблоны → Компоненты Windows → Службы удалённых рабочих столов → Узел сеансов удалённых рабочих столов → Подключения → Разрешить удалённый запуск неперечисленных программ» — «Включено».
В домене политику может задать и запретить администратор домена: если она запрещена, локальная настройка не поможет.

---

## 4. Включить в VibeRDP

1. В подключении: «Рабочий стол» — «Окна Windows», включить «Сначала пробовать RemoteApp»
2. Подключиться

Как понять, что сработало:
- Окно «Проводника» приходит отдельным окном Мака сразу, без рабочего стола на экранах
- В журнале ([diagnostics.md](diagnostics.md)) категория `rail`: `the program started`

Если Windows RemoteApp не разрешила, VibeRDP сам переподключается без него и работает через хелпер или рабочим столом; в журнале `RemoteApp refused` и `connecting again without RemoteApp`.

---

## 5. Чего в RemoteApp нет

- Иконок программ в Dock: RemoteApp не сообщает, какой программе принадлежит окно
- Меню «Пуск» на Маке: его даёт хелпер, а в сеансе RemoteApp автозагрузка Windows не выполняется
- Графического конвейера с H.264: каждое окно рисуется в общий кадр старыми кодеками, на медленной сети картинка может обновляться медленнее, чем в режиме хелпера
