# Документация VibeRDP

```
docs/
├── idea.md           # концепт и архитектура — исходный стартовый промпт, историческая запись
├── roadmap.md        # план по этапам: один чекбокс — одна итерация
├── decisions.md      # решения на развилках: варианты, выбор и почему
├── manuals/          # руководства «как сделать» по шагам
│   └── devSetup.md   # среда разработки, сборка ядра и её проверки
└── knowledge/        # база знаний: грабли и проверенные факты с источниками
    ├── README.md     # индекс — запись без строки здесь не существует
    ├── freerdp/      # сборка FreeRDP и OpenSSL
    ├── macos/        # AppKit и буфер обмена
    ├── rdp/          # протокол RDP и его расширения
    └── windows/      # Win32 и среда хоста, где работает хелпер
```

Имена файлов и папок в `docs/` — camelCase; исключения только для общепринятых верхнеуровневых: `README.md`, `roadmap.md`, `functional.md`, `idea.md`.
Каталог возможностей `functional.md` появится с первой пользовательской возможностью.
Каноничная спецификация канала Seam живёт вне `docs/` — в `protocol/seam-protocol.md` (задача 4.1).

## Соответствие путям из стартового промпта

Промпт ([idea.md](idea.md)) называл документы по-своему; в репозитории они лежат по стандарту семейства:

| В промпте | В репозитории |
|---|---|
| `VibeRDP-PROMPT.md` в корне | [idea.md](idea.md) |
| `ROADMAP.md` | [roadmap.md](roadmap.md) |
| `knowledge.md` | [knowledge/](knowledge/README.md) — записи по доменам с индексом; «как собрать» — [manuals/devSetup.md](manuals/devSetup.md) |

Остальные пути промпта — `core/`, `client-macos/`, `helper-win/`, `protocol/`, `.vibe/` — без изменений.
